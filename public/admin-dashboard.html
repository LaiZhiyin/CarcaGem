How to read these metrics

An effective start requires at least one completed human turn. Deep play means three net human turns in the same game during this period, or a completed game with at least one human turn by the player.

Browser IDs cannot be merged across devices. Local games are reported by the client; online games are confirmed by the server.

Measurement limits

Connection time is measured on the same device with a monotonic clock and includes connection setup and processing; it is not one-way network latency. “—” means there are no samples.

Web Vitals, time to an interactive board, and revision sync diagnostics are future experience metrics; this page does not substitute estimates for uncollected measurements.

Collection & storage

Internal test traffic

Mark future visits from this browser as internal tests. Reopen the game after enabling this; production reports exclude these events by default.

Legacy data

Legacy databases are stored separately. Client “game start” logs do not prove a game occurred; historical records cannot provide completion rates or campaign attribution.

Daily history summary

Daily totals are kept for up to 730 days; UV across days cannot be added to calculate period UV. Event details are kept for 90 days. Results are grouped by environment; source filters do not apply.

Metric definitions & coverage

The start of the current metric definition, latest accepted event, and data environment are shown separately. New visitors are identifiable browsers; clearing storage, private browsing, or switching devices can break continuity. Local games without an end signal remain “unconfirmed” and are not treated as deliberate exits.

Visits where analytics cannot run are outside measurement coverage. If a report fails, the last successful data remains visible with a delay notice; values are not replaced with zeros or default distributions.
